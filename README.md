# 業務データ処理ツール（Portfolio 01）

CSV の **読み込み → 整形 → 検証 → 重複検出 → 照合 → 集計 → 出力** を、設定ファイル（JSON）に沿って自動で行う Windows 向けデスクトップアプリです。
「毎月の受注 CSV と入金 CSV を目で突き合わせている」「表記ゆれを手で直している」といった定型業務の自動化を想定しています。

| 項目 | 内容 |
| --- | --- |
| 言語 | Python 3.11 以上 |
| 画面 | Tkinter（標準ライブラリ。追加インストール不要） |
| データ処理 | pandas |
| 入出力 | CSV（UTF-8／Shift_JIS 自動判定）、JSON、HTML レポート |
| テスト | pytest（111 件） |
| 費用 | すべて無料（ネット接続・外部サービスなし） |

## できること

1. **CSV の読み込み**：文字コード（UTF-8・Shift_JIS）を自動で判定。空行は読み飛ばし、列の数が合わない行は「エラー」として記録（処理は止めない）
2. **整形**：全角英数字→半角、「2026年1月5日」「2026/1/5」→`2026-01-05`、「1,200円」「▲500」→`1200`・`-500`、電話番号の「ー」→「-」、メールの小文字化、前後の空白除去
3. **検証**：必須項目・データ形式（整数・日付・メール・電話番号）・最小値／最大値・文字数・書き方（正規表現）・使える値の一覧・行のルール（例：合計金額＝数量×単価）
4. **重複データの検出**：キー列（例：注文番号）が同じ行を見つけ、最初の1行だけを残す
5. **複数ファイルの照合**：2つの CSV をキーで突き合わせ「一致／不一致／片方にだけある」に分ける（例：受注 × 入金で、未入金・金額違い・注文のない入金を見つける）
6. **集計・レポート**：月別・商品別などの合計・件数・平均・最大・最小・種類数。HTML のレポートも作成
7. **CSV・JSON 出力**：整形済み・正常データ・エラー一覧・重複一覧・変更記録・照合結果・集計を出力。Excel で開いても文字化けしない形式（BOM 付き UTF-8）
8. **処理履歴・エラーログ**：毎回の処理を履歴（JSON Lines）に残し、想定外のエラーはログファイルに詳細を記録

設定ファイルを差し替えれば、受注データ以外の CSV（会員名簿・勤怠・在庫など）にも使えます。

## はじめに（初回だけ）

PowerShell でこのフォルダを開き、次を順に実行します。

```powershell
py -3.11 -m venv .venv
```

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

## 使い方

画面を開く：`start.bat` をダブルクリック（または次のコマンド）。左のメニューでページを切り替え、ダッシュボードで結果をカードとグラフで見られます。左下のボタンでライトモード・ダークモードを切り替えられます（次に開いたときも残ります）。

```powershell
.\.venv\Scripts\python.exe -m dataprep
```

コマンドで処理する（同じ処理を自動化したいとき）：

```powershell
.\.venv\Scripts\python.exe -m dataprep run -i samples\orders.csv -p profiles\orders.json -r samples\payments.csv -o output
```

そのほかのコマンド：`history`（処理履歴）、`check-profile 設定ファイル`（設定の書き方チェック）。詳しくは [操作マニュアル](docs/05_操作マニュアル.md)。

## 見本データ

`samples/` の CSV はすべて架空のデータです（`python samples/make_samples.py` で作り直せます）。

- `orders.csv`：受注 42 行（Shift_JIS）。表記ゆれ・エラー・重複をわざと入れてある
- `payments.csv`：入金 38 行（UTF-8）。未入金・金額違い・注文のない入金を含む

処理すると「正常 30 行／エラーのある行 12 行」「一致 36・不一致 1・受注のみ 3・入金のみ 1」になります。

### 試しに使ってみる用のデータ（`samples/trial/`）

もう少し多い件数で、画面やグラフを試したいとき用です（`python samples/make_trial.py` で作り直せます）。どちらも設定ファイルは `orders.json` を選びます。

| 処理するCSV | 照合するCSV | 内容 | 処理した結果 |
| --- | --- | --- | --- |
| `受注_10-11月.csv`（122 件・Shift_JIS） | `入金_10-11月.csv`（116 件・UTF-8） | 10〜11月の注文。表記ゆれ・エラー 6 件・重複 2 件・未入金・入金額の違いを少しだけ含む | 正常 114 行・エラーのある行 8 行／一致 113・不一致 2・受注のみ 5・入金のみ 1 |
| `受注_きれい.csv`（50 件） | `入金_きれい.csv`（50 件） | 問題のないデータ（「正常ならこう見える」の確認用） | 正常 50 行・エラー 0／一致 50 |

## テスト

```powershell
.\.venv\Scripts\python.exe -m pytest
```

## フォルダ構成

```
dataprep/          プログラム本体
  config.py        設定ファイル（JSON）の読み込みとチェック
  fileio.py        CSV・JSON の読み書き（文字コード判定・CSV インジェクション対策）
  cleaning.py      整形
  validation.py    検証
  duplicates.py    重複検出
  reconcile.py     照合
  aggregate.py     集計
  report.py        HTML レポート
  history.py       処理履歴・ログ
  pipeline.py      一連の処理のまとめ役
  cli.py           コマンド
  gui/             画面（Tkinter）：app.py 画面、charts.py カード・グラフ、theme.py 配色、widgets.py 部品
profiles/          設定ファイルの見本
samples/           見本データ（架空）
tests/             自動テスト
docs/              設計書・テスト仕様・操作マニュアル
```
