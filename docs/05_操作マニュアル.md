# 05 操作マニュアル

## 1. 準備（初回だけ）

1. Python 3.11 以上を入れる（`py --list` で確認できる）
2. PowerShell でこのフォルダを開き、次を実行する

```powershell
py -3.11 -m venv .venv
```

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

## 2. 画面で使う

1. `start.bat` をダブルクリックする（左にメニュー、右にダッシュボードが出る）
2. 左のメニューの **ファイルと実行** を開く
3. **処理するCSV** の「参照…」でファイルを選ぶ（選ぶと「データ」に中身が出る）
4. **設定ファイル** を選ぶ（受注データなら `orders.json`）。下に設定の概要が出る
5. 照合したいときは **照合するCSV（任意）** を選ぶ（受注データなら入金 CSV）
6. 右上の **処理を実行** を押す。終わるとダッシュボードに切り替わる
7. 結果を見る
   - ダッシュボード：件数のカード、いちばん多い・少ない項目（右上で「集計」と「比べる値」を選べる）、グラフ
   - エラー一覧：どの行の何が問題か。上の欄で絞り込める
   - データ・重複・照合・集計・処理履歴：左のメニューから開く
8. 右上の **出力フォルダを開く** で CSV などを、**レポートを開く** で HTML のまとめを見る

**明るい画面にしたいとき**：左下の「ライトモードにする」を押す（戻すときは「ダークモードにする」）。次に開いたときも同じ表示で開く。

文字化けするときは「ファイルと実行」の「文字コード」で UTF-8 か Shift_JIS を選び直す。

**試しに使ってみるとき**：`samples/trial/` の `受注_10-11月.csv`（処理するCSV）と `入金_10-11月.csv`（照合するCSV）を選び、設定ファイルは `orders.json` のまま「処理を実行」する。エラーのない場合の見え方は `受注_きれい.csv` と `入金_きれい.csv` で試せる（どちらも架空のデータ）。
### エラーを直す流れ（例）

1. 「エラー一覧」で行番号と内容を確認する
2. 元の CSV（または元のシステム）を直す
3. もう一度「処理を実行」する（結果は新しいフォルダに保存され、前の結果は消えない）

## 3. コマンドで使う

```powershell
.\.venv\Scripts\python.exe -m dataprep run -i 受注.csv -p profiles\orders.json -r 入金.csv -o output
```

| オプション | 内容 |
| --- | --- |
| `-i` / `--input` | 処理する CSV（必須） |
| `-p` / `--profile` | 設定ファイル（必須） |
| `-r` / `--reconcile` | 照合する CSV |
| `-o` / `--out` | 出力先（既定 `output`） |
| `--encoding` | auto / utf-8 / shift_jis |
| `--fail-on-error` | エラーが 1 件でもあれば終了コード 1（定期実行で通知したいとき） |

終了コード：0＝完了、1＝完了したがエラーあり（`--fail-on-error` のとき）、2＝処理できなかった。

そのほか：

```powershell
.\.venv\Scripts\python.exe -m dataprep history
```

```powershell
.\.venv\Scripts\python.exe -m dataprep check-profile profiles\orders.json
```

## 4. 新しい CSV 用の設定を作る

1. `profiles/orders.json` をコピーして名前を変える
2. `name`・`columns`（列名は CSV の見出しと同じに）を書き換える
3. 重複を見たい列を `keys` に、集計したい切り口を `aggregations` に書く
4. `check-profile` で書き方を確かめる

書き方の詳細は [詳細設計書 3 章](03_詳細設計書.md)。

## 5. 困ったとき

| 表示 | 対処 |
| --- | --- |
| 文字コードを判定できませんでした | Excel などで UTF-8 か Shift_JIS の CSV として保存し直す |
| 必須の列がありません | 設定ファイルの種類が CSV に合っているか、見出しの名前が違っていないか |
| 設定ファイルの書き方に誤りがあります（○行目） | その行の `,` `"` `}` の付け忘れを確認する |
| 想定外のエラー（受付番号 …） | `data/logs/dataprep.log` で受付番号を検索し、内容を開発者に伝える |

履歴・ログ・画面の設定（表示モード）は `data/` フォルダにある（消しても動作には影響しない）。
