# 01 要件定義書

## 1. 背景と目的

小規模事業者や事務部門では、システムから出力した CSV を Excel で開き、表記ゆれの修正・入力ミスの確認・別ファイルとの突き合わせ・集計を手作業で行っていることが多い。
本ツールはこの定型作業を **設定ファイル1つで再現できる自動処理** に置き換え、作業時間とミスを減らすことを目的とする。

## 2. 想定する業務シナリオ

ネットショップの運営担当者が、毎月次の作業をしている。

1. ショップの管理画面から受注 CSV（Shift_JIS）をダウンロードする
2. 表記ゆれ（全角数字・日付の書き方など）を直し、入力ミスを確認する
3. 決済サービスの入金 CSV（UTF-8）と注文番号で突き合わせ、未入金・金額違いを探す
4. 月別・商品別・支払方法別の売上を集計する

## 3. 利用者

- 事務担当者：画面で CSV と設定を選んで実行する（プログラムの知識は不要）
- 管理者（開発者）：設定ファイル（JSON）を作る・直す。コマンドで定期実行する

## 4. 機能要件

| No | 機能 | 内容 |
| --- | --- | --- |
| F1 | CSV 読み込み | UTF-8（BOM 有無）・Shift_JIS を自動判定。区切り文字を設定できる。空行は読み飛ばす。列数の合わない行はエラーとして記録し処理を続ける |
| F2 | 整形 | 型ごとに表記ゆれを統一する（全角→半角、日付→YYYY-MM-DD、金額の「,」「円」除去など）。変更の前後を記録する |
| F3 | 検証 | 必須・型・範囲・文字数・正規表現・選択肢・行のルール（積の一致、大小比較） |
| F4 | 重複検出 | キー列または行全体で重複を検出。最初の行を残し2件目以降をエラーにする |
| F5 | 照合 | 2ファイルをキーで突き合わせ、一致・不一致・片方のみに分類。数値は差額と許容差を扱う |
| F6 | 集計・レポート | グループ（月・年・任意の列）ごとに件数・合計・平均・最大・最小・種類数。合計行。HTML レポート |
| F7 | 出力 | CSV（Excel 向け BOM 付き UTF-8）と JSON |
| F8 | 履歴・ログ | 処理ごとに履歴を1行追記。想定外のエラーはログに詳細を残す |
| F9 | 画面 | ファイル選択・プレビュー・実行・結果の表示（タブ）・絞り込み・履歴表示 |
| F10 | コマンド | 画面と同じ処理をコマンドで実行（定期実行・自動化用） |

## 5. 非機能要件

| 項目 | 要件 |
| --- | --- |
| 動作環境 | Windows 10 / 11、Python 3.11 以上 |
| 費用 | 無料のソフトだけで動く。ネット接続不要 |
| 性能 | 10 万行程度の CSV を実用的な時間（数十秒以内）で処理できる。ファイルの上限は 200MB |
| 使いやすさ | 画面・メッセージはすべて日本語。処理中も画面が固まらない |
| 信頼性 | 入力ファイルは書き換えない。処理結果は実行ごとに別フォルダに保存し、上書きしない |
| 安全性 | 出力 CSV を Excel で開いても数式が動かない（CSV インジェクション対策）。レポートに入力値が命令として埋め込まれない（XSS 対策）。エラー画面に内部情報を出さない |
| 保守性 | 業務ルールはコードではなく設定ファイルで変える。処理ごとにモジュールを分け、自動テストを用意する |

## 6. 対象外（今回は作らない）

- データベースへの保存（Portfolio 02 で扱う）
- Excel ファイル（.xlsx）の直接読み書き
- 設定ファイルを画面で編集する機能（JSON をテキストエディタで編集する）
- 複数人での同時利用・ログイン

## 7. 受入条件

- 見本データ（`samples/`）で、整形・検証・重複・照合・集計がすべて設計どおりの件数になる（テスト仕様書 IT-01〜IT-04）
- 自動テストがすべて成功する
- セキュリティチェック20項目で「×」がない
