# 06 セキュリティチェック（20項目）

実施日：2026-11-22（画面の作り替えのあと 2026-11-23 に再確認）。本ツールは **PC の中だけで動くデスクトップアプリ**（ネット通信・ログイン・データベース・AI 機能なし）なので、該当しない項目は同じ役割のもので確かめた。

そのほかの配慮：

- 入力ファイルは書き換えない。出力は実行ごとに新しいフォルダ（上書きしない）
- 履歴には入力ファイルの中身ではなく、ファイル名と SHA-256（同じファイルか確かめる値）だけを残す
- 見本データの名前・メール・電話番号はすべて架空（メールは example.com）
- 画面の設定（`data/settings.json`）に保存するのは表示モード（dark / light）だけ。知らない値や壊れたファイルは無視する（UT-21・22）
